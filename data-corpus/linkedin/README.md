# LinkedIn Exports

Drop your LinkedIn data export here.

**How to get it:** LinkedIn → Settings → Privacy → Get a copy of your data

Expected files:
- `Profile.csv` — Your complete profile data
- `Connections.csv` — Your network
- `Endorsement_Received_Info.csv` — Skill endorsements
- `Recommendations_Received.csv` — Written recommendations
- `Skills.csv` — All listed skills
- Any other exported files
