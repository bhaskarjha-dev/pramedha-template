# Visual & Media Evidence

Drop screenshots, presentation slides, photos, and media assets here.

## What Goes Here
- Metric proof: public or personal project dashboards (Google Analytics, public Grafana, open-source metrics) proving performance improvements or user growth (no internal or employer dashboards)
- Project screenshots: public application UI, personal design system component libraries, architecture diagrams
- Public appearances: photos from conference talks, workshop sessions, panel discussions
- Presentation decks: PDF or PPTX slides from public technical talks or webinars
- Certificates as images: photos or scans of physical certificates, diplomas, badges

> Media files serve as high-tier evidence referenced in `identity/claims-and-evidence.md` to turn claims into verifiable facts.
