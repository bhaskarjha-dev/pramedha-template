# Platform Data Exports

Drop data exports, profile backups, and analytics reports from third-party platforms here.

## What Goes Here
- Job board exports: Naukri, Indeed, Wellfound (AngelList), Dice
- Technical & community platforms: Kaggle profiles/notebooks, Hugging Face models/cards, Stack Overflow data, LeetCode profile
- Creator & writing platforms: Substack archives, Medium exports, Dev.to/Hashnode article lists
- Open-source package registries: PyPI, npm, crates.io published package listings

> Note: For LinkedIn exports, use `data-corpus/linkedin/`. For GitHub archives, use `data-corpus/github/`.
