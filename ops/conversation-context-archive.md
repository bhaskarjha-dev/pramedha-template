# Conversation Context Archive — Founding Session

> **Purpose:** Captures all research, decisions, artifacts, and context from the initial
> conversation(s) that created this career operating system. This is different from
> `session-handoff.md` — that file logs ongoing sessions. This file preserves the
> comprehensive context of the *founding* session.
>
> **Rule:** Write this ONCE at the end of your initial template population session.
> It is a permanent record, not a living document.
>
> **Why this matters:** The initial fill session is the highest-context, highest-decision
> moment in the repo's life. You discover contradictions, resolve data gaps, make naming
> decisions, and build a mental model of the person's career. Without archiving this
> context, future sessions lose the "why" behind hundreds of decisions.
