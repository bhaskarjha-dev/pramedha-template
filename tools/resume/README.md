# Satellite Resume Engine (RenderCV & Typst)

> **Decoupled On-Demand Compiler:** `identity/*.yaml` (Source of Truth) → `sync.py` → `master.yaml` → `variants/*.yaml` → `assemble.py` → RenderCV PDF

This directory is an **on-demand satellite tool**. It is completely decoupled from daily career repository operations. Core career maintenance never requires editing or maintaining `master.yaml` directly. When targeting a specific application, use `sync.py` to forward-bridge facts into `master.yaml`, tailor a variant, and compile.

---

## Architecture & Data Flow

```
identity/*.yaml (Source of Truth)
      │
      ▼  py tools/resume/sync.py (Forward Bridge)
master.yaml (RenderCV Bullet Bank, keyed by role + phrasing)
      │
      ▼  × variants/*.yaml (Thin overlays selecting bullets per target JD)
      │  + design.yaml (Theme, typography, margins)
      │
      ▼  py tools/resume/assemble.py
generated/*.yaml (Auto-assembled RenderCV YAML)
      │
      ▼  RenderCV / Typst CLI
output/*.pdf (Targeted ATS-compliant PDFs)
```

---

## Quick Start (On-Demand Tailoring)

```bash
# 1. Forward-sync verified facts from identity/ into master.yaml
py tools/resume/sync.py

# 2. Create or edit a role variant in variants/ (copy variants/_template.yaml to your-role.yaml)
# 3. Build & Render PDF (1-Step):
pwsh tools/resume/build.ps1        # Windows
./tools/resume/build.sh            # Linux/macOS
```

## File Reference

| File | Edit? | Purpose |
|------|:-----:|---------|
| `master.yaml` | ⚡ SYNC | RenderCV bullet bank (auto-synced from `identity/` via `sync.py`; can enrich with phrasings) |
| `design.yaml` | ✏️ YES | Visual theme, margins, typography (shared across variants) |
| `variants/*.yaml` | ✏️ YES | Role-specific bullet, project, and summary selection overlays |
| `sync.py` | ⚡ RUN | Forward bridge: extracts verified facts from `identity/` into `master.yaml` |
| `assemble.py` | ⚡ RUN | Cascade engine: merges `master` + `design` + `variants` → `generated/*.yaml` |
| `generated/*.yaml` | ❌ NO | Auto-generated RenderCV YAML with JSON schema. DO NOT EDIT. |
| `output/*.pdf` | ❌ NO | Rendered PDFs |

## Modern Tooling & Integrations

### 1. JSON Schema Autocomplete
All assembled YAML files generated by `assemble.py` include the RenderCV v2.8 JSON Schema header:
```yaml
# yaml-language-server: $schema=https://raw.githubusercontent.com/rendercv/rendercv/refs/tags/v2.8/schema.json
```
Your editor (VS Code, Cursor, Neovim) will provide immediate autocompletion, field docs, and error highlighting.

### 2. AI Assistant Skill (`rendercv-skill`)
If you use Claude Code, Cursor, or AGY agents to refine your resumes, you can install the official RenderCV AI agent skill:
```bash
npx skills add rendercv/rendercv-skill
```
This arms AI assistants with full AST-verified knowledge of RenderCV's schema and constraints.

### 3. Web App Workflow (`rendercv.com`)
RenderCV offers a companion browser app at [rendercv.com](https://rendercv.com) with live WebAssembly rendering, visual form editing, and GitHub repository synchronization. You can copy any generated YAML file from `tools/resume/generated/` into the web app for instant browser previews.

## Master YAML Structure

```yaml
# master.yaml — Keyed bullet pool
header:
  name: "Your Name"           # Auto-filled from ../../identity/identity.yaml or ../../config.yaml
  # ... contact info

experience:
  role_key:                    # Unique key for this role/position
    company: "Company Name"
    position: "Job Title"
    start_date: "2023-06"
    end_date: "present"
    location: "City, State"
    # archived: true           # Optional: marks historic role retained in pool
    bullets:
      bullet_key:              # Unique key for this bullet
        default: "Full bullet text with metric [measured]"
        short: "Shortened version"
        technical: "Tech-focused phrasing"
        leadership: "Leadership/management phrasing"

projects:
  project_key:
    name: "Project Name"
    date: "2024"
    location: "github.com/you/repo"
    bullets:
      default: "One-line project description with impact"

publications:
  - title: "Publication Title"
    authors: ["First Author", "Second Author"]
    date: "2024"
    journal: "Journal / Conference"
    url: "https://doi.org/..."
```

## Variant YAML Structure

```yaml
# variants/genai.yaml — Selects from master for GenAI roles
variant_name: "GenAI Engineer"
output_filename: "Your_Name_GenAI_CV"
summary: "One-paragraph summary for this variant"
experience:
  role_key:                    # Must match a key in master.yaml
    - [bullet_key, default]    # [key, phrasing] or just [key]
    - [other_bullet_key]       # Uses "default" phrasing
projects:
  - project_key               # Keys from master.yaml projects section
publications: true            # Include all publications from master.yaml (or list subset)
technologies:
  - label: "GenAI"
    details: "RAG, LLM APIs, Vector DBs, vLLM"
```
